# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | shows the contents of the current folder |
|     cd directory_name       | enter the specified folder |
|     cd ..                   | return to the parent folder |
|     cd -                    | return to the folder you were in previously |
|     mkdir directory_name    | create a new folder |
|     touch filename          | create an empty file |
|     git status              | check which changes in the repository have not been committed yet |
|     git add -A              | put all the changes into the staging area |
|     git commit -m ""        | records the staged changes as a commit, with a message describing the changes |
|     git push                | push local commits to the remote repository |
|     git pull                | fetch updates from the remote repository and merge them into the local one |
