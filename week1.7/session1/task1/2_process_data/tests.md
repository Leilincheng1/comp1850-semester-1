# Week 1.7, Session 1: Task 1

Equivalence classes for `process_data(data)`:

| List data | Values and expected results |
| --- | --- |
| Empty list | `[] -> None` |
| Single integer list | `[0] -> 0`, `[7] -> 7`, `[-4] -> -4` |
| Multiple integer list | `[1, 2, 3] -> 6`, `[-2, -3] -> -5`, `[5, -5, 0] -> 0` |
